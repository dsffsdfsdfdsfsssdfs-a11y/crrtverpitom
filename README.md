# Озёрский питомник

Готовый статический HTML-макет питомника с каталогом, корзиной и встроенным редактором.

## Публикация через GitHub и Vercel
1. Распакуйте архив и загрузите файлы из папки `ozerskiy-pitomnik` в корень GitHub-репозитория.
2. В Vercel выберите Add New → Project → Import Git Repository.
3. Framework Preset: Other; Build Command: пусто; Output Directory: пусто (корень проекта).
4. Нажмите Deploy.

## Важно
Это статический сайт. Корзина и редактор работают на стороне браузера; для получения заказов на сервер потребуется отдельно настроить отправку заявок.
Перед публикацией проверьте контакты, цены и изображения.
