# Центр размножения растений

Сайт питомника на Next.js. Контентные блоки вынесены в `app/page.tsx`, чтобы их можно было быстро обновлять.

## Развитие админ-панели

Для настоящего управления сайтом без правки кода (изменение телефонов, текста, фото и прайсов) нужно подключить защищённую базу и файловое хранилище к Vercel. Интерфейс и дизайн сайта готовы к этому этапу; после подключения можно добавить закрытый кабинет администратора.
